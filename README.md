# DOSH Store

نسخة أولية قابلة للتعديل مستوحاة من تصميم موقع DOSH الظاهر في صور Pomelli.

## التشغيل
افتح `index.html` في المتصفح.

## لوحة التحكم
افتح `admin.html`.
الرمز التجريبي: `1234`.

## مهم قبل الإطلاق
هذه النسخة تستخدم localStorage للتجربة، وليست قاعدة بيانات آمنة لمتجر إنتاجي.
للإطلاق الحقيقي نربط الواجهة بقاعدة بيانات وخادم مصادقة، ثم نضيف الدفع والشحن وإدارة الطلبات.

## المزايا الموجودة
- منتجات وتصنيفات
- أسعار ومخزون
- مقاسات وألوان
- سلة مشتريات
- إرسال الطلب عبر واتساب
- لوحة إدارة لإضافة/تعديل/حذف المنتجات
- تصميم RTL ومتجاوب للموبايل
